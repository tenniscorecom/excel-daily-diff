# 延期積上集計

日付ごとに並んだ `一覧_YYYYMMDD.xlsx` を**隣り合う日どうしで順に突き合わせ**、
**延期**（前の日にあって次の日にない）と**積み上げ**（前の日になくて次の日にある）を、
日ごとに数えて Excel に出します。

毎日更新される一覧から「消えた行」「増えた行」の推移を追う、という形の業務なら
列名を設定で合わせるだけで使えます。

[comken](https://github.com/tenniscorecom/original_libs)（業務自動化用の共通ライブラリ）を
使った利用プロジェクトの例でもあります。

## 特徴

- **列名・シート名・期間・絞り込み条件をすべて `config.ini` から変えられる。**
  読み取り元が変わってもコードを直さない
- **日付を2つの役割に分けている。** 表の横軸は「ファイル名の日付」（いつ時点の一覧か）、
  絞り込みは「案件の日付が対象月に入っているか」。混ぜると、先の日付を持つ
  新規案件が範囲外に落ちて**積み上げだけ0件**になる
- **絞り込みは後から足せる。** `[EXCLUDE_CONTAINS]` などに `列名 = 語` を1行書くだけ
  （含む／完全一致 × 残す／外す の4種類）
- **列名を打ち間違えたら実行時に止まる。** 黙って0件になったり全部消えたりしない
- 1ファイル数万行を想定し、1行ずつ読む（全件をメモリに載せない）
- 出力は集計シート（件数）と明細シート（内訳）の2枚

## 出力の形

|  | 標準 4/21 | 4/22 | … | 上位 4/21 | 4/22 | … |
|---|---|---|---|---|---|---|
| 積み上げ | 3 | 1 | | 1 | 0 | |
| 延期 | 1 | 0 | | 0 | 2 | |

横は**ファイル名の日付**です。`4/21` の列は「4/20 のファイルと 4/21 のファイルを比べた結果」。
指定期間を1日も飛ばさず並べます（件数0の日を詰めると前後の週と見比べられないため）。
ファイルが無い日は、件数0と区別できるよう空セルにします。

## セットアップ（初回だけ）

1. `実行.bat` を1度動かす。`config.ini.example` から `config.ini` が作られるので、値を書き換える
2. `実行.bat` の先頭 `COMKEN_ROOT` を、共有サーバー上の comken の場所に合わせる

## 実行

- `実行.bat` をダブルクリック（または `python main.py`）
