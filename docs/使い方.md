# 使い方

このツールの操作手順（実行する人向け）。エンジニアでなくてもこのページだけ読めば使えるようにする。

---

## このツールは何をするもの？

`一覧_20260812.xlsx` のように日付が入ったファイルが並んだフォルダを見て、
**隣り合う日どうしを順に見比べて、日ごとの増減を数えます。**

| 出てくる言葉 | 意味 |
|---|---|
| **延期** | 前の日のファイルにあったのに、その次の日のファイルから消えた行 |
| **積み上げ** | 前の日のファイルになかったのに、その次の日のファイルに増えた行 |

数えるのは、次の3つすべてに当てはまる行だけです。

1. 「予定日」が、**業務日の月**（例: 業務日が 2026年8月の列なら 8月）の中にある
2. 「種別」が **標準** または **上位** で始まる
3. 「状態」が **完了** または **予定**

**業務日で対象月を決めるのは、「1月の列は 1月の案件の積み上げ・延期を見たい」という
集計意図に沿うため**です。実行日が 8月でも、業務日 1月の列は 1月の案件だけを見ます。

### 日付が2種類出てきます

ここがいちばん間違えやすいところです。

| | 何の日付か | どこに効くか |
|---|---|---|
| **業務日**（= ファイルの日付 - 1日） | いつ動いたか（= ファイル名の日付 - 1日） | **集計.csv の列に並ぶ日付**（入力フォルダの最新ファイルまで自動） |
| **予定日**（表の中の列） | その案件の日 | **数える／数えないの判断**にだけ使います |

ファイル名と業務日が1日ずれているのは、**入力ファイル `一覧_YYYYMMDD.xlsx` が前日終了時点のデータ**
だからです。たとえば `一覧_20260825.xlsx` の中身は 8/24 終了時点の状態を指し、
`一覧_20260824.xlsx` との差分は「8/24 に動いたぶん」を表すので、業務日 8/24 の列に入ります。

つまり「**8月の案件について、入力フォルダにある一番古いファイルから一番新しいファイルまでの毎日、
何件延期して何件積み上がったか**」という表が出ます。

**読み込むのは今年の1月1日から今日まで**の範囲に入っているファイルだけです。
フォルダに何年ぶん溜まっていても、それより古いファイルは開きません。
1月に実行したときは、前年12月のファイルが比較相手として1件だけ読まれます。

> **初回は、1年ぶんのファイルを読むため時間がかかります**（最大で約240件）。
> 日々の実行は増分計算なので、遅いのは最初だけです。
>
> **年が変わると下限も新しい年の1月1日に切り替わります。** 増分実行では前年の列が
> そのまま残りますが、絞り込み条件を変えて CSV を消して作り直すと前年の列は消えます。

## 初回だけやること（1回でOK）

1. **設定ファイルを用意する**
   `実行.bat` を1度動かす（または `python main.py` を実行する）と `config.ini` が作られて止まります。
   メモ帳で開いて、次の2か所を自分の環境に合わせて書き換えてください。

   | 書き換える場所 | 何を書くか |
   |---|---|
   | `INPUT_FOLDER` | `一覧_20260812.xlsx` が並んでいるフォルダの場所 |
   | `OUTPUT_FOLDER` | 集計.csv を出したい場所 |

   **`START_DATE` / `END_DATE` / `TARGET_MONTH` の指定は不要です。** 集計対象月は
   業務日から、横軸の日付は前回作った `集計.csv` の最後の日付から自動で決まります。
   月が変わっても `config.ini` を書き換える必要はありません。

2. **列の名前が合っているか確認する**
   `config.ini` の `[SOURCE]` に「顧客番号」「予定日」「種別」「状態」と書いてあります。
   元のファイルの見出しがこれと違う場合は、**元のファイルに合わせて書き換えてください。**

---

## 毎回の使い方

1. ターミナルで `実行.bat` を叩く（または `python main.py` を実行する）
2. 黒い画面が出て処理が進む
3. 画面が閉じたら完了。`OUTPUT_FOLDER` に **`集計.csv`** ができています
   （毎回同じ名前で上書きされます。日付の入ったファイル名にはなりません）

`実行.bat` には `pause` を入れていないので、画面は一瞬で閉じる。エラーが起きたときは終了コードで
判断できる（タスクスケジューラや RPA 基盤から呼ぶときも同様）。

---

## 出てくる CSV の見方

**`集計.csv` の見方**

- **行**は **常に 4 行**（対象月「当月」「来月」 × 判定「積み上げ」「延期」）。
  種別（標準/上位）の内訳は無く、合算のみ
- 「対象月」列の中身は実際の暦月（`2026-04` 等）でなく、業務日基準の
  相対ラベル **`当月`** と **`来月`**。業務日自身の月が「当月」、翌月が「来月」
- **列**が **業務日**（`2026-04-21` の形式）。`4/21` の列は「**4/21 に動いたぶん**」、つまり
  「4/20 のファイルと 4/21 のファイルを比べた結果」です（ファイル名より1日早い）
- 件数が0の日も列として並びます（日付が飛ばないようにするため）
- **業務日が無い日（土日など）は空セル**になります。
  - `0` は「**比べた結果0件**」（ファイルはあったが件数が0だった）
  - 空セルは「**比べられなかった**」（ファイルが無い、そのラベルの対象月の前／後、など）

例（一部）:

| 対象月 | 判定 | 2026-04-21 | 2026-04-22 | 2026-04-23 |
|---|---|---|---|---|
| 当月 | 積み上げ | 3 | 1 | 0 |
| 当月 | 延期 | 1 | 0 | 1 |
| 来月 | 積み上げ | 1 | 0 | |
| 来月 | 延期 | 0 | 2 | |

> **このツールを新しい形式で使い始めるときは、既存の `集計.csv` を一度消してから
> 実行してください。** 行・列の構成を大きく変えたため、古い
> 「種別」列ありの `集計.csv` をそのまま使うと整合性が崩れます。
> 絞り込み条件を変えたときと同じく、`OUTPUT_FOLDER` の `集計.csv` を
> 削除 → 実行 の流れで作り直してください。

## 絞り込み条件を変えたとき（注意）

`config.ini` の絞り込み（`[FILTER]` の `KINDS` / `PLAN_PREFIXES`、あとから足した
`[INCLUDE_CONTAINS]` など）を書き換えると、過去ぶんの数値も本来は変わります。
このツールは条件変更を自動では検知しないので、**新しい条件で全期間を作り直したい場合は
`OUTPUT_FOLDER` にある `集計.csv` を消してから実行してください。**
消すのを忘れると、CSV には古い条件で書かれた過去ぶんが残ったまま、列の末尾だけ
新しい条件で追記される形になります。

## 条件を足したいとき（プログラムを直さずにできます）

「地域に離島が入っているものは数えたくない」のような条件は、`config.ini` の
下のほうにある**4つの欄に1行書き足すだけ**で増やせます。

| 書く欄 | どういう条件になるか |
|---|---|
| `[EXCLUDE_CONTAINS]` | その言葉が**入っている**行を、集計から**外す** |
| `[INCLUDE_CONTAINS]` | その言葉が**入っている**行**だけ**を数える |
| `[EXCLUDE_EXACT]` | その言葉と**ぴったり同じ**行を、集計から**外す** |
| `[INCLUDE_EXACT]` | その言葉と**ぴったり同じ**行**だけ**を数える |

書き方は `列の名前 = 言葉` です。言葉はカンマで並べられます。

```ini
[EXCLUDE_CONTAINS]
地域 = 離島, 山間部
```

これで「地域に離島**または**山間部が入っている行」が集計から外れます。

**気をつけること**

- **列の名前は、元のファイルの見出しとまったく同じに書いてください。**
  打ち間違えると `ExcelColumnNotFoundError` で止まります（間違ったまま
  0件になったり全部消えたりはしません）
- **列の名前に「・」や「（）」やスペースが入っていても、そのまま書けます。**
  例: `住所・地域 = 離島` / `氏名（カナ） = テスト`
  唯一使えないのは **`=`** です（`=` の左が列名、右が言葉、という区切りに使うため）
- 元のファイルの見出しに余分なスペースが入っていても（`備考 ` のような場合でも）、
  スペースは自動で落として照合します。`config.ini` にはスペースなしで書いてください
- 複数の欄に書いた場合は「**そのすべてを満たす行だけ**」が残ります
- 使わない欄は、中身を空のままにしておけば無視されます
- **書いた言葉は、元のファイルの表記とぴったり合わせてください。**
  英字の大文字・小文字、全角・半角は別の文字として扱われます
  （`ＡＢＣ` と `ABC` は違うものになります）
- 言葉の区切りにカンマを使うので、**カンマそのものを含む言葉は指定できません**
- 実行したとき黒い画面に
  `追加の絞り込み: 地域 が 離島 を含む行を外す`
  と出ます。ここで意図どおりか確認できます

## うまくいかないとき

- 黒い画面に赤い英語（エラー名）が出たら、**[ERRORS.md](ERRORS.md)** でその名前を探して対処する
- 解決しないときは、**画面全体をスクリーンショット**して管理者に送る

## よくある質問

**Q. 出力ファイルはどこ？**
A. `config.ini` の `OUTPUT_FOLDER` に設定した場所です。**ファイル名は `集計.csv` で固定**
（日付の入った名前は付きません。毎回同じファイルを上書きします）。

**Q. 月が変わったら `config.ini` を書き換える必要がありますか？**
A. **不要です。** 集計対象月は業務日から自動で決まります（業務日が属する月をそのまま使う）。
実行日（= ツールを起動した日）は対象月の判定に影響しません。
そのまま `実行.bat` を叩いてください。

**Q. 横に並ぶ日付の範囲を変えたい**
A. 設定からは指定できません。範囲は **前回作った `集計.csv` の最後の業務日の次の業務日** から
**入力フォルダにある最新ファイルの日付** までの範囲で自動で決まります（列は業務日で並ぶので、
最後のファイル日付 - 1日 が最後の業務日）。
過去ぶんを作り直したい場合は、`集計.csv` を消してから実行してください（全期間を作り直します）。

**Q. 土日を挟んでファイルが飛んでいる日は？**
A. その業務日の列は空欄になり、**次にファイルがある業務日は「飛んだ手前のファイル」と比べます**。
金曜と月曜のファイルしかなければ、月曜の業務日列は「金曜と月曜を比べた結果」です。

**Q. 元のファイルは書き換わりませんか？**
A. 読み取り専用で開くので、元のファイルには一切書き込みません。

**Q. 「日付として読めない行が◯件ありました」と出た**
A. 「予定日」の欄に日付でない文字が入っている行です。その行だけ集計から外しています。
元のファイルを確認してください。

**Q. 積み上げが1件も出ない**
A. 集計対象月は業務日から自動で決まりますが、絞り込み条件（`PLAN_PREFIXES` や `KINDS`、
追加の絞り込み）が合っていない可能性があります。黒い画面の「条件に合う行 ◯件」が
極端に少なくないか見てください。業務日 D の列では、D の対象月の外の案件は
増えても減っても数えません。
